# Kaly PHP framework

> A small modular PSR HTTP framework with convention-based routing and first-class dependency injection

Kaly is built on PHP standards: PSR-7 messages, PSR-11 container, PSR-15 middleware.
It provides a small application model with modules, a convention-based router and a
preconfigured dependency injection container, without becoming a full-stack framework.
